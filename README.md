# MyWeb

新生实践 · WEB 设计基础 作业工程（Dreamweaver）。

## 工程说明

- 本地工作区：`MyWeb/`
- 远端仓库：`git@github.com:XKT666/MyWeb.git`
- 默认分支：`main`

## 常用命令

```bash
git status              # 查看改动
git add -A && git commit -m "更新页面"
git push                # 推送到 GitHub
git pull                # 拉取远端更新
```

## 目录约定

- 页面文件（`*.html` / `*.css` / `*.js`）
- 静态资源（`images/`、`media/`）
- Dreamweaver 的 `_notes/` 同步说明不纳入版本库
